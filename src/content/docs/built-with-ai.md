---
title: Built with AI – on purpose
description: How Kasmin is developed.
---

Kasmin is developed with heavy use of AI. Most of the code, the tests and the documentation are written together
with Claude, an AI assistant by Anthropic; I plan the features, review the changes and decide what is released.
Every change goes through the same automated tests, code analysis and security scans before it is released.

For me, Kasmin is also a test run: I want to find out how far a real, useful open-source application can be built
and maintained with intensive AI support, and where its limits are. I will share what I learn along the way.

Commits made with AI help are marked as co-authored by Claude, so you can see in the history what was written how.
